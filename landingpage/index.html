Why ccse

专为多 Agent 开发者打造的全链路闭环

告别多工具配置碎片化。一次变更，自动兼顾前缀路由、子模型跟随、凭证安全与状态自愈。

🧬

Subagent 智能跟随，保留路由前缀

--model 不只换顶层主模型。OpenCode 的 4 个 agent 槽位（build/explore/general/plan）、OpenClaw 的 subagent 槽位、Claude 的 CLAUDE_CODE_SUBAGENT_MODEL 均智能跟随主模型，且各槽位自动保留已配置的路由前缀（如 newapi/...），Claude 专属 [1M] 上下文标记全自动补全。

model: 'newapi/gemini-3.8-flash' → 'newapi/claude-sonnet-5-5'
env.CLAUDE_CODE_SUBAGENT_MODEL: 'glm-5.3-flash[1M]' → 'claude-sonnet-5-5[1M]'
🛡️

写前快照与双重 Undo

任何变更落盘前，目标文件全量备份到 ~/.ccse/snapshots/。若配置异常，运行 ccse undo 秒级恢复。恢复时还会自动留存 pre-restore 镜像，杜绝二次丢失。

$ ccse undo 20261017-094120
restored 6 file(s) safely ✓

双通道端点探测 Verify

换完自动测通：GET /v1/models 校验 Bearer 密钥与模型可用性，Gemini 执行原生 v1beta 探活。模型缺失即时 WARN 预警，发现 401 立即标记 FAIL。

🧠

Rules 行为注入 (caveman+rtk)

模型是结构，规范是灵魂。ccse rules --apply 幂等注入极简输出规则与 rtk 命令行代理，单机开发大幅节省 60%~90% 的上下文 Token 损耗。

<!-- ccse:caveman-rtk:START -->
Idempotent injection across 25 rules
📦

Penv 项目级 .env 快速切换

在 ~/.ccse/providers.toml 沉淀提供商模板，ccse penv ./project myprov 一键覆写项目 .env 中的 Key、Base URL 与 Model 变量。

$ ccse penv ./myproject newapi
3 env variables updated in .env

Quickstart

一分钟极速安装

使用 uv 或 pipx 安装，全局独立环境运行，无依赖冲突。

# 方式 1: 推荐 uv 直接全局安装
$uv tool install git+https://github.com/Tonystarkw12/cc-switch-enhanced

# 方式 2: 克隆仓库本地安装 (pipx 亦同理)
$git clone https://github.com/Tonystarkw12/cc-switch-enhanced.git
$cd cc-switch-enhanced && uv tool install .

# 立即体验全 fleet 模型切换
$ccse --model "glm-5.2"
