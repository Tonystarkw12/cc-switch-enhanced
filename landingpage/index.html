37个适配器

个 AI 编程助手，一行命令同时切换模型、端点与 key。

ccse 读写每个 agent 的原生配置：Claude Code、Codex、opencode、Gemini、Qwen Code、aider……换聚合端不再逐个改文件。写前自动快照，ccse undo 一键回滚。

安装

单机 CLI，本地运行；配置文件写完即生效，无后台、无账号。

# 一行安装（uv，直接装 GitHub 主分支）
$ uv tool install git+https://github.com/Tonystarkw12/cc-switch-enhanced
# 或克隆后本地安装；pipx 同理（pipx install .）
$ git clone https://github.com/Tonystarkw12/cc-switch-enhanced
$ cd cc-switch-enhanced && uv tool install .
# 切换
$ ccse --model "glm-5.2"

Windows 支持 setx 持久化 env 型变量；升级 uv tool upgrade cc-switch-enhanced 或重跑安装命令加 --force。

一行切换，写前快照

ccse --model "glm-5.2"

全 fleet 主模型一键切换，subagent 槽位跟随，claude 自动补 [1M] 标记。

ccse --base-url U --api-key K

端点与 key 同步切换；env 型 agent 的 key 写入 ~/.zshrc（Windows 走 setx）。

ccse apply <profile>

按 ~/.ccse/profiles.toml 配方回切整套组合；genprofile 把当前状态抓成配方。

ccse verify

写完探测每个端点：key 是否有效、模型是否在列表里，FAIL 退出码 1。

ccse undo

恢复最近一次 apply 的写前快照，恢复前再备份一层，不会二次丢数据。

改动可撤回

  • 写前快照每次 apply 先把要改的文件存进 ~/.ccse/snapshots/，ccse undo [stamp] 任意回滚。
  • 原子写临时文件 + os.replace；解析失败即中止，不碰原文件。
  • 预览先行--dry 与 ccse diff 只打印差异，不落盘。
  • 坏配置不炸批某个 agent 配置损坏时跳过并告警，其余照常切换。
  • key 不留痕show/verify 只显示前 6 位；history 记录对 key 脱敏。

换聚合端，不该是一个个改配置文件。
